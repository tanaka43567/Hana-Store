# Luxora Store

Landing page toko online elegan yang dibuat dengan HTML, CSS, dan JavaScript sederhana.

## Cara jalankan lokal

```bash
cd C:\Users\OPHIR\3d-web
npx serve . -l 8000
```

## Deploy ke Netlify atau Vercel

1. Upload folder ini ke GitHub.
2. Buka Netlify atau Vercel.
3. Pilih repository yang baru di-upload.
4. Deploy dengan opsi default.
